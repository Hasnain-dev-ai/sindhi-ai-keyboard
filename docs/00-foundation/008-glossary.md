### Sindhi AI Keyboard
The primary product of the project: a Sindhi-first, multilingual, AI-powered keyboard designed for Sindhi, Urdu, and English users.

### SGoC
Abbreviation for **Solangi Group of Companies**, the intended organizational/business identity associated with the project and future ventures.

### Solangi Group of Companies
The broader organizational identity intended to support Sindhi AI Keyboard and future technology projects.

### Sindhi AI Platform
The long-term ecosystem vision into which Sindhi AI Keyboard and Sindhi SDK may eventually expand.

### Sindhi SDK
The planned software development kit that will expose Sindhi language and AI capabilities to developers and applications.

### Project
Unless otherwise specified, "the Project" means Sindhi AI Keyboard and its associated technology ecosystem.

### Repository
The source-code repository containing the project documentation, application code, assets, models, tests, tools, and supporting infrastructure.

# 3. ⌨️ Keyboard Terms

### Keyboard Engine
The core software responsible for processing keyboard input and producing reliable text output.

### Keyboard Service
The operating-system-level service through which the keyboard becomes available for text input.

### Layout
The arrangement and mapping of keys, characters, numbers, punctuation, symbols, and controls.

### Windows Layout
The established Windows-style Sindhi keyboard arrangement used as the reference for the mobile keyboard experience.

### Mobile Layout
The mobile adaptation of the reference keyboard layout while preserving familiar character placement and typing behavior.

### Language Switcher
The control used to switch between Sindhi, Urdu, and English input.

### Prediction
The process of suggesting likely words or phrases based on the user's input and context.

### Autocorrection
Automatic correction of likely typing errors.

### Smart Suggestion
A context-aware suggestion generated from language data, models, user input, or enabled Skill Packs.

### Shortcut
A predefined key, phrase, word, sentence, or action intended to reduce repetitive typing.

### Phrase Shortcut
A shortcut that expands a short input into a predefined phrase or sentence.

### Word Shortcut
A shortcut that expands a short input into a predefined word.

### Toolbar
The keyboard area containing additional tools and actions such as language controls, AI tools, OCR, voice input, and other features.

### Active Text Field
The text-entry field in another application where keyboard output is currently being inserted.

### Typing Latency
The delay between user input and visible keyboard/text response.

### Typing Interruption
Any event that disrupts or noticeably interferes with normal typing.

# 4. 🌐 Language Terms

### Sindhi
The primary language for which the project is being built and optimized.

### Urdu
One of the core supported languages alongside Sindhi and English.

### English
One of the core supported languages and the reference language for standard QWERTY interaction where applicable.

### Script
The writing system used to represent a language.

### Sindhi Script
The Arabic-derived script used for written Sindhi and supported by the project.

### Unicode
The international character encoding standard used to represent text consistently across devices and applications.

### Transliteration
Representing words from one writing system using characters from another writing system.

### Translation
Converting meaning from one language into another language.

### Language Detection
Identifying the language represented by text or speech.

### Dictionary
A structured collection of words, terms, definitions, forms, or language resources used by the application.

### Language Model
A computational model that estimates or generates language based on learned patterns.

### Tokenizer
A component that divides text into tokens suitable for processing by language models or other NLP systems.

### Token
A unit of text processed by a language model or language-processing system.

### Corpus
A collection of language data used for research, training, evaluation, or linguistic analysis.

### Sindhi Mega Corpus
The large Sindhi language dataset supplied for use within the project's language and AI development process.

# 5. 📦 Pack System Terms

### Skill Pack
A modular package containing language data, models, terminology, rules, features, or domain intelligence for a specific purpose.

### Core Pack
The foundational pack required for the basic keyboard experience.

### Language Pack
A pack containing resources for a particular language.

### Domain Pack
A Skill Pack specialized for a professional, social, educational, or practical domain.

### Agriculture Pack
A domain pack intended for agricultural use cases such as plants, crops, vegetables, fruits, seeds, nursery terminology, and related information.

### Education Pack
A domain pack intended for students, teachers, educational writing, and academic use.

### Government Pack
A domain pack intended for government terminology, official writing, forms, and related workflows.

### Healthcare Pack
A domain pack intended for healthcare-related terminology and workflows.

### Legal Pack
A domain pack intended for legal terminology and document-related workflows.

### Business Pack
A domain pack intended for commercial and business communication.

### Pack Manager
The component responsible for installing, updating, enabling, disabling, and removing Skill Packs.

### Pack Recommendation
A non-intrusive recommendation for a Skill Pack based on device capability, enabled languages, user needs, or usage context.

### Unified Configuration
The default configuration used when the user has not explicitly selected a specialized pack configuration.

### Pack-Based Architecture
The architectural principle that separates optional functionality and resources into modular packs rather than loading everything into every installation.

### Device-Aware Packs
Pack behavior that considers device capabilities and resource limitations before recommending or loading additional resources.

# 6. 🤖 AI Terms

### AI
Artificial Intelligence.

### On-Device AI
AI processing performed locally on the user's device.

### Cloud AI
AI processing performed on remote infrastructure through a network connection.

### Hybrid AI
An architecture that combines local and cloud AI processing.

### AI Writing Assistant
A feature that assists with writing, rewriting, grammar, paraphrasing, tone, summarization, translation, and related tasks.

### Rewrite
Generating an alternative version of existing text while attempting to preserve its intended meaning.

### Paraphrase
Expressing the same meaning using different wording or structure.

### Grammar Assistance
AI or rule-based assistance for improving grammatical correctness.

### Tone Transformation
Changing the style or tone of text, such as making it formal, simple, professional, friendly, or concise.

### Context-Aware AI
AI that considers surrounding text, language, application context, or enabled domain resources.

### Model
A trained computational system used for prediction, recognition, generation, classification, or other AI tasks.

### Quantization
Reducing the numerical precision of a model to decrease size and computational requirements.

### Inference
The process of executing a trained AI model to produce an output.

### Sindhi OCR

### Real-Time OCR

### Document OCR
OCR applied to documents, forms, letters, notices, records, or other structured text.

### Camera Tool
A keyboard-integrated visual feature that allows users to capture or analyze images.

### Vision AI
AI systems capable of interpreting visual information.

### Plant Recognition
Identification or classification of plants from visual input.

### Crop Recognition
Identification or classification of agricultural crops.

### Seed Recognition
Identification or classification of seeds from visual information.

### Visual Intelligence
The broader capability of the system to understand and process images and visual information.

# 26. 📝 Glossary Maintenance Rules

This glossary should evolve with the project.

A new term should be added when:

1. It becomes important to architecture.
2. It is repeatedly used in documentation.
3. It has a project-specific meaning.
4. It could otherwise cause ambiguity.
5. It becomes part of a public API.
6. It becomes part of the user-facing product.

Terminology should remain:

- Clear
- Consistent
- Technically accurate
- Understandable
- Stable where possible

Major terminology changes should be documented in the project changelog and, where appropriate, an Architecture Decision Record.
