# 🤝 Support

## Sindhi AI Keyboard

> **Built for the community. Supported by the community. Designed for everyone.**

Sindhi AI Keyboard is being developed as an **ad-free, privacy-first, offline-first** keyboard and, ultimately, a broader Sindhi AI Platform.

We want the project to remain useful not only for technically experienced users, but also for people using older devices, limited connectivity, and different levels of digital literacy.

# 🐛 Bug Reports

A bug is an unintended behavior of the application.

Examples:

* Keyboard crashes
* Keyboard disappears
* Keys do not respond
* Characters appear incorrectly
* Language switching fails
* Layout behaves incorrectly
* Prediction behaves unexpectedly
* A Skill Pack fails to load
* OCR fails unexpectedly
* Translation does not work as expected
* Offline functionality fails

When reporting a bug, provide as much useful information as possible.

### Recommended information

```text
Device:
Android version:
Sindhi AI Keyboard version:
Installed Skill Packs:
Language/layout:
Online or offline:
What happened:
What you expected:
Steps to reproduce:
Screenshots/video if useful:
```

Do **not** include private conversations, passwords, financial information, personal documents, or other sensitive information in bug reports.

---

# 🐢 Performance Problems

Performance issues are especially important because the project is designed for users with a wide range of devices.

Please report issues such as:

* Slow keyboard startup
* Typing latency
* Delayed key response
* Excessive RAM usage
* Battery drain
* Device overheating
* AI processing delays
* OCR delays
* Translation delays
* Keyboard freezing

Device information is particularly useful for performance investigations.

---

# 📡 Offline & Connectivity Issues

Offline-first operation is a core project requirement.

```text

________________

Actual:

```

The core keyboard should remain usable even when cloud services are unavailable.

# 📱 Device Compatibility

Sindhi AI Keyboard is intended to support a broad range of devices.

Because device capabilities vary significantly, some advanced AI features may behave differently depending on:

* RAM
* Storage
* CPU
* GPU
* NPU
* Android version
* Battery condition
* Thermal limitations

The project may recommend different Skill Packs or models depending on device capability.

This is intended to prevent unnecessary resource usage and preserve a smooth keyboard experience.

# 🔐 Security Vulnerabilities

**Do not report security vulnerabilities through ordinary public support channels.**

Security issues may expose:

* User information
* Authentication systems
* API credentials
* Backend infrastructure
* Keyboard input
* AI systems
* Device data

Please follow the instructions in:

```text
SECURITY.md
```

Security vulnerabilities should be handled privately and responsibly.

* Passwords
* API keys
* Access tokens
* Private keys
* Financial information
* Private conversations
* Private documents
* Personal identification documents
* Private photographs
* Sensitive health information
* Confidential business information
* Other people's private information

# 🌾 Rural & Low-Connectivity Users

A major goal of the project is to serve users who may have:

* Poor internet
* Expensive mobile data
* Older phones
* Limited storage
* Limited technical knowledge

Therefore, support and product decisions should not assume:

> "Everyone has fast internet."

Whenever practical, troubleshooting should provide an offline path.
